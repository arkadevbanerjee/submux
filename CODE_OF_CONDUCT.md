# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the
work. Harassment, personal attacks and discriminatory language are not
tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Report conduct concerns privately to the maintainer,
[@arkadevbanerjee](https://github.com/arkadevbanerjee), through GitHub.
Reports are handled confidentially. The maintainer may remove content,
lock threads or block contributors who break these standards.
